C Calculator Documentation

A simple calculator written in C that runs in your terminal.

About

C Calculator is a lightweight command-line calculator written in the C programming language. It allows users to enter mathematical expressions directly into their terminal.

Installation

1. Create the source file

Open your terminal and create a file called main.c.

cat > main.c <<'EOF'

Paste the calculator source code from the repository into the file.

2. Compile

Compile the program using Clang:

clang main.c -o calculator

3. Run

Start the calculator:

./calculator

Using the Calculator

Enter a mathematical expression after the Math: prompt.

Math: 2+2
4

Math: 10*5
50

Math: (10+5)*2
30

Supported Operations

  • Addition (+)
  • Subtraction (-)
  • Multiplication (*)
  • Division (/)
  • Parentheses ( )
  • Decimal numbers
  • Negative numbers

Quitting

Type q and press Enter to close the calculator.

Supported Systems

  • Linux
  • Windows Terminal (with a C compiler)
  • macOS
  • Termux
  • ChromeOS Linux environment

Features

  • Written in C
  • 64-bit floating-point calculations
  • Multiple numbers in one expression
  • Basic mathematical operations
  • Error handling
  • Division-by-zero detection
  • Simple terminal interface
  • Quit using Q
